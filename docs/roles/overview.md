title: Roles at a glance
---

Every person in your organization has one role. The role decides which actions are available. Everyone with an account can open the screens for their organization in read-only form unless noted.

| Area | Administrator | Manager | Accountant | Auditor | Viewer |
| --- | :---: | :---: | :---: | :---: | :---: |
| View dashboard, invoices, retainage | Yes | Yes | Yes | Yes | Yes |
| View cash ledger transactions | Yes | Yes | Yes | Yes | No |
| Create and edit projects | Yes | Yes | No | No | No |
| Delete projects | Yes | No | No | No | No |
| Request change orders | Yes | Yes | No | No | No |
| Approve or reject change orders | Yes | No | No | No | No |
| Daily diary, site schedule, attendance | Yes | Yes | No | No | No |
| Add and edit labour records | Yes | Yes | No | No | No |
| Remove labour records | Yes | No | No | No | No |
| Create subcontracts and payment claims | Yes | Yes | Yes | No | No |
| Certify payment claims | Yes | No | Yes | No | No |
| Cost codes | Yes | Yes | Yes | No | No |
| Record and delete ledger transactions | Yes | No | Yes | No | No |
| Move and issue stock | Yes | Yes | Yes | No | No |
| Add customers, vendors and catalog items | Yes | No | Yes | No | No |
| Delete customers and vendors | Yes | No | No | No | No |
| Collect online payment for an invoice | Yes | No | Yes | No | No |
| Organization settings, lists and labels | Yes | No | No | No | No |
| See the team list | Yes | No | No | No | No |

:::note
Read-only roles (Auditor and Viewer) can open screens but cannot create, change or delete anything.
:::
